# DE_IP_2024 — Task 1: базовая обработка SAR-изображения

Лабораторная работа по обработке изображений: работа с радарным (SAR) снимком в оттенках серого.

## Что сделано

1. Загрузка изображения в оттенках серого.
2. Гистограмма (обычная и накопленная).
3. Гамма-коррекция (γ < 1 и γ > 1), реализованная вручную.
4. Сравнение исходного и скорректированных изображений по MSE и SSIM.
5. Статистическая цветокоррекция на основе среднего и СКО `eq_gray` (результат `cv2.equalizeHist`).
6. Пороговая фильтрация: разные значения порога, типы порога, Otsu, Triangle, адаптивный порог, влияние предобработки и сглаживания.
