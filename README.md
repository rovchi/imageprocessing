# DE_IP_2024 — лабораторные работы по обработке изображений

Работа с радарными (SAR) снимками: NumPy, OpenCV, Matplotlib, scikit-image.

## Task 1 — базовая обработка изображения

Ноутбук: `DE_IP_2024_Task_1_solution.ipynb` · изображение: `sar_1_gray.png`

1. Загрузка изображения в оттенках серого и гистограмма.
2. Гамма-коррекция (γ < 1 и γ > 1), сравнение по MSE и SSIM.
3. Статистическая цветокоррекция на основе статистики `eq_gray` (результат `cv2.equalizeHist`).
4. Пороговая фильтрация: разные пороги и типы порога, Otsu, Triangle, адаптивный порог.

## Task 2 — наложение и удаление шума

Ноутбук: `DE_IP_2024_Task_2_solution.ipynb` · изображение: `sar_1.png`

1. Зашумление: гауссов шум и постоянный (импульсный) шум «соль и перец».
2. Тест четырёх фильтров с разными параметрами: медианный, Гаусса, билатеральный, нелокальных средних.
3. Сравнение по MSE и SSIM относительно оригинала, выбор лучшего фильтра для каждого типа шума.

Итог: для гауссова шума лучше всего сработал фильтр Гаусса с ядром 3×3, для шума «соль и перец» — медианный фильтр с окном 3.
